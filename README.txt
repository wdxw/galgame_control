Gal Controller
==============

Gal Controller 是一个面向 Windows 的视觉小说（Galgame）游戏库管理器，
用于扫描、整理、查看和启动本地视觉小说收藏。

主要功能
--------

- 扫描指定目录，自动识别视觉小说安装目录和可执行文件。
- 自动寻找本地封面；没有封面时可提取游戏 EXE 图标。
- 通过 VNDB 搜索和下载视觉小说封面、描述、开发商和发售日期。
- 打开游戏详情页时，按已保存的 VNDB 作品 ID 查询准确评分与投票数。
- 导入 VNDB 封面后自动查询 Bangumi 评分，匹配不确定时可选择对应版本，并跳转评分网站。
- 支持收藏、最近游玩、搜索、排序、编辑详情、打开游戏目录和启动游戏。
- 支持中文和 English 界面。
- 默认使用浅粉色二次元主题，详情页使用当前游戏封面作为全窗口背景。
- 支持深色、深暗色、粉色、二次元和透明淡粉主题切换。
- 透明淡粉主题使用淡粉渐变、半透明毛玻璃面板和深玫瑰色文字，可在设置中选择并保存。

技术栈
------

- Electron
- React
- TypeScript
- Vite / electron-vite
- Tailwind CSS
- Zustand
- SQLite（better-sqlite3）
- VNDB API

开发运行
--------

安装依赖：

    npm install

启动开发环境：

    npm run dev

生成生产文件：

    npm run build

生成 Windows 未打包版本和安装包：

    npm run package

打包输出
--------

未打包程序：

    build/win-unpacked/GalController.exe

Windows 安装包：

    build/gal-controller-1.0.0-setup.exe

使用说明
--------

1. 启动 Gal Controller。
2. 点击侧边栏的“导入游戏”，选择包含视觉小说的目录。
3. 扫描完成后选择要加入游戏库的项目。
4. 点击游戏卡片查看详情，详情页会尝试读取 VNDB 评分。
5. 使用详情页中的“更换封面”可以浏览本地图片、提取 EXE 图标或搜索 VNDB。

三维世界
--------

点击侧边栏“三维世界”进入主世界：一座圆润质感的小岛，有广场、小屋、植被、
河流和星空码头。WASD 或方向键漫游，也可以点击地面让角色走过去；
斜俯视跟随相机会在建筑挡住视线时自动让开。每个已关联 VNDB 的作品都有
属于自己的星球，从码头或星球目录（可搜索、可翻页）进入。

星球场景按作品资料生成：地形、建筑、地标、配色和氛围各不相同，推理与悬疑类
作品保持昏暗基调。场景下方显示资料同步状态；点击世界特色物件即可启动对应的
本地游戏，也可以使用启动按钮。在“世界特色”面板中可以查看识别依据、增删物件
并指定启动装置；玩家自己的修改优先于生成结果。已识别的元素暂时没有模型时，
会以占位物件保留位置，便于之后补上。

“建造”工具可以摆放、移动、旋转和删除物件，支持撤销与位置预览，摆放不会挡住
出生点与入口；光标落在不能摆放的位置时地面会变红，并说明原因（超出小岛范围、
广场要留出空地、不要挡住出生点通道、码头要保持通畅、这里已经有景物了）。
“重新生成世界”按新布局重建场景，玩家的摆放与特色覆盖项仍会保留。

三维世界界面跟随“设置”中的界面语言（中文 / English），切换语言不会重建场景。

每个世界的布局、特色覆盖项、启动物件和生成版本都保存在本机 SQLite 数据库中；
旧版本存放在 localStorage 里的摆放记录会在首次进入时自动迁移，迁移成功后清除。

导入游戏时，开启 VNDB 联网查询的应用只会自动关联名称完全吻合的作品；未自动
匹配的作品可在详情页通过“更换封面”搜索并选择 VNDB 条目，即使该条目没有封面
也能建立关联。设置中的“画面质量”默认使用独立显卡渲染，中、低档位减少特效与
植被密度，切换后当前世界立即按新档位重建。

联网 AI 分析（可选）：配置并启用后，应用把作品的标题、简介和非剧透标签交给 AI，
按限定结构与模型清单校验结果并缓存；未配置时保持规则识别。普通进入世界不会
重复请求，重新关联 VNDB 作品会丢弃旧关联尚未完成的结果。

世界回归检查：

    npm run test:world:ui
    npm run test:world:bench
VNDB 与 Bangumi 评分
--------------------

导入 VNDB 封面并保存作品后，会自动查询 VNDB 和 Bangumi 评分。
已导入的作品在下次打开详情页时补查，无需重新导入封面。
优先使用已保存关联或 VNDB 的 Bangumi 外部链接；名称不唯一或日期冲突时，
请在候选列表核对原名、发售日期与版本后选择。重新匹配时取消不会删除已有选择。
更换为另一部 VNDB 作品会清除旧的 Bangumi 关联。

每个来源分别展示分数、评分人数和更新时间；“查看评分”会使用默认浏览器打开作品页。
评分缓存有效期为 24 小时，断网时可显示旧缓存并注明更新时间。
公开接口可能无法返回部分成人条目；访问受限、无评分和未匹配会分别提示。
设置中的 VNDB 联网开关同时控制这两项评分查询，关闭后不自动联网。
评分失败不会阻塞封面导入或游戏启动。

评分回归检查：

    npm run test:ratings
    npm run test:ratings:ui

测试在 build 下创建隔离的数据目录，使用模拟接口验证匹配与 UI，不访问个人游戏库。

批评空间手动评分
----------------

详情页的“批评空间”卡片始终标注“手动录入”。点击“录入”或“编辑”，填写作品链接或数字 ID。
支持 koko.kyara.top/game.php?game=ID，以及 erogamescape.org、erogamescape.dyndns.org 的
/~ap2/ero/toukei_kaiseki/game.php?game=ID 作品页。裸 ID 使用 koko 入口；粘贴链接保留原站点。
中位数评分可空，范围 0–100；评分人数可空，须为非负整数。零分与零人数会如实保存。
保存后展示原始百分制分数、人数和录入时间。取消编辑不修改数据，清除需再次确认。

这些操作只读写本地数据库，不自动访问批评空间或镜像；仅“查看评分”会打开默认浏览器。
关闭 VNDB 联网开关后仍可使用手动评分。更换 VNDB 作品会清除旧关联；普通标题编辑或
同一作品换封面会保留评分。删除游戏时一并删除该游戏的手动记录。

完整封面显示
------------

详情背景使用同图模糊铺满窗口，左侧清晰图片在标题栏和右侧详情面板之间完整展示。
大图等比例缩小，小图不放大，四周保留边距；右侧预览同样限制放大。
详情滚动不改变左侧封面大小，点击面板外仍可关闭。游戏卡片已取消悬停时的图片缩放。

评分网站显示
------------

在游戏详情页展开“评分网站显示”，分别勾选 VNDB、Bangumi 或批评空间。
显示设置对所有游戏生效，重启后保留。隐藏不会清除已保存的评分、作品关联或手动记录。
全部取消勾选后仍可展开此入口恢复显示。
