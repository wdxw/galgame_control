# 世界音乐：网易云音乐

日期：2026-10-02

进入作品世界时，现在会分别加载网易云搜索结果、VNDB 关联专辑和游戏目录音频。网易云使用作品原名搜索专辑与歌曲，原名没有结果时尝试游戏库中的显示名称；窗口提供「全部 / 网易云 / VNDB / 本地」来源切换，也可以手动输入游戏名、专辑名或曲名搜索。

搜索结果显示来源、专辑封面、艺术家、曲名和时长。网易云专辑下的曲目是搜索命中的部分歌曲，界面明确标示此范围，并提供整张专辑的官方播放器。单曲选择加载网易云官方外链播放器，本地文件继续使用本地播放器。切歌保持一个云播放器；两种音频来源不会同时播放。

2026-10-03 已加入[后台播放与切换修复](./world-music-background-2026-10-03.md)：关闭音乐窗口、切换世界、查看游戏库和最小化窗口会继续当前音乐；启动实际游戏时自动停止。底部播放条提供持续可用的播放控制，播放组件不随作品世界重建。

网易云查询与 VNDB 的联网开关相互独立。查询结果缓存 24 小时，刷新失败可回退已有缓存。搜索无结果、部分结果和网络失败分别显示提示，仍可打开网易云搜索页面。查询内容只使用作品名称或用户输入的关键词。

## 核验结果与限制

- 主进程、界面类型检查和生产构建通过。服务检查覆盖独立搜索、原名回退、专辑与曲目去重、输入校验、缓存键、部分失败和断网状态。
- 网络请求回归共 18 项通过，包含网易云表单编码和现有 JSON 查询兼容。
- 2026-10-02 当时的完整世界界面回归通过，包含来源切换、无需本地音频的云选曲入口、单曲切换、整张专辑入口、手动搜索、云搜索失败时 VNDB 继续可用、播放器关闭与离开世界回收，以及原有 10 类世界交互。关闭窗口与离开世界的行为已在后续[后台播放更新](world-music-background-2026-10-03.md)中改为继续播放。
- 真实网易云查询返回《邪悪宣言 装甲悪鬼村正 オリジナルサウンドトラック》、《MURAMASA》和《Raven Steel》等专辑，并在世界内显示《落葉》等真实歌曲。官方播放器可加载歌曲信息；当前环境中《落葉》的外链播放进度仍停在零，未验证成功出声。外链页面还报告第三方脚本跨域错误。窗口保留「前往网易云」入口供平台页面播放或登录，不保证所有歌曲可在外链中播放，也未绕过付费、登录或地区限制。
- 外链播放器位于独立网页框架中，不授予本地游戏库、游戏启动或 Node API；应用预加载桥仅向主页面开放。

本地截图输出：真实网易云窗口 `build/world-ui-mufH9e/world-muramasa-netease-live.png`，界面回归 `build/world-ui-JBFqZu/world-netease-music.png`。截图属于被忽略的测试产物，不随源码上传；重新运行测试时会生成新的输出目录。

数据与播放器来自[网易云音乐](https://music.163.com/)。使用作品名称的公共搜索，以及平台提供的[外链播放器](https://music.163.com/outchain/player?type=2&id=4942751&auto=0&height=66)。

## 解包版
