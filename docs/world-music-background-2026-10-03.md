# 世界音乐后台播放与切换修复

日期：2026-10-03

旧解包版把播放器放在作品世界的音乐窗口内，离开世界或关闭音乐窗口会移除播放器。此次把本地音频和网易云外链播放器统一放到应用层，世界窗口负责查找专辑和选曲。进入另一作品世界、返回主世界、切换游戏库、关闭音乐窗口和最小化窗口均保留同一个播放器和当前播放进度。

播放时显示底部播放条，标示曲名、所属游戏和来源。可展开或收起播放控制，本地音频可暂停、继续，所有来源均可停止。不同世界的新搜索结果不会自动换歌。启动游戏的统一接口会先停止音频、清空本地音频源并移除云播放器，然后再调用游戏启动程序；世界内物品、启动按钮、游戏卡片和详情页均使用该接口。

## 验证

- 两种界面的类型检查和生产构建通过。
- 使用解包版中的界面文件与预加载桥完成专项验收：有效 WAV 和独立网页框架中的音频在关闭窗口、最小化、进入不同世界、切换游戏库和重返世界后进度持续前进，播放器节点身份保持相同。
- 世界物品和游戏库卡片启动流程通过：在游戏启动处理函数接收请求时，音频已暂停、本地音频源已清空、云框架已移除、底部播放条已隐藏。
- 独立网页音频夹具没有本地应用 API 和 Node 权限。
- 解包版完整世界回归通过，覆盖音乐来源切换、选曲、专辑播放、搜索失败回退、10 类场景、高台移动、村正妖刀入口、启动绑定、建造编辑与保存、中英文切换，未出现界面错误。
- 两个解包目录的 EXE 和应用包逐字节一致，全部 5 个编译文件与应用包一致；使用各自打包的数据库和图像依赖实际完成 SQLite 查询与 PNG 编码。

云播放器的持续播放检查使用包含真实音频的独立网页夹具，不代表所有网易云曲目均可在官方外链中播放。网易云原有的登录、版权和地区限制仍按平台处理。自行打开的外部浏览器网页不受应用播放条控制。

本地截图输出：跨世界播放 `build/world-ui-wP3rxn/background-cloud-world.png`，本地播放控制 `build/world-ui-wP3rxn/background-local-controls.png`。截图属于被忽略的测试产物，不随源码上传；重新运行测试时会生成新的输出目录。

## 解包版

本次本地验收已更新 `build/win-unpacked/GalController.exe` 与 `build/win-unpacked-music/GalController.exe`。构建产物保留在本机；从源码生成解包版请在仓库根目录运行 `npm run package`。使用新版时重新打开程序，并保留其所在目录的其他文件。

专项验收入口是 `scripts/test-world-ui.cjs` 的 `WORLD_UI_BACKGROUND_ONLY=1` 模式；设置 `WORLD_UI_APP_ASAR` 为解包目录内的 `resources/app.asar` 时，可直接验证该解包版中的界面和预加载桥。
